ASCLIN0 UART 드라이버 설계 (Echo 예제)

TC237 Aurix Project  |  DrvUart.c / DrvUart.h  |  작성일: 2026-05-02

1. 개요

ASCLIN0 모듈을 사용하여 PC와 115200 bps UART 통신을 구현한다. USB-TTL 변환기를 통해 PC 터미널과 연결하며, PC에서 전송한 문자를 TC237이 그대로 되돌려 보내는 Echo 기능을 기본 예제로 제공한다.

항목내용
UART 모듈ASCLIN0
TX 핀P15.2 (IfxAsclin0_TX_P15_2_OUT) → X102 커넥터 31번 핀
RX 핀P15.3 (IfxAsclin0_RXB_P15_3_IN) → X102 커넥터 32번 핀
통신 속도115200 bps
데이터 포맷8 Data bits, No Parity, 1 Stop bit (8-N-1)
SW FIFOTX 256 byte / RX 64 byte
동작 예제PC → 'a' 전송 → TC237 수신 → 'a' 회신 (Echo)

2. 하드웨어 연결

2.1 핀 연결도

USB-TTL 신호색상(일반)TC237 핀X102 위치비고
GND검정GNDpin 3 또는 4반드시 연결
TX (변환기 송신)초록P15.3 (RX)pin 32변환기 TX → TC237 수신
RX (변환기 수신)흰색P15.2 (TX)pin 31TC237 송신 → 변환기 RX
VCC (3.3V)빨강연결 안 함—TC237 자체 전원 사용
교차 연결 원칙: TX ↔ RX 는 항상 반대로 연결. 변환기의 TX(송신)는 TC237의 RX(수신)에, 변환기의 RX(수신)는 TC237의 TX(송신)에 연결.

2.2 전체 연결 구성

  PC                USB-TTL 변환기              TC237 X102 커넥터
  ──                ──────────────              ─────────────────
  USB ─────────────▶ (CP2102/CH340)
                        GND  ─────────────────  GND       (pin 3)
                        TX   ─────────────────  P15.3 RX  (pin 32)
                        RX   ◀────────────────  P15.2 TX  (pin 31)
                        VCC  ─── X ───────────  (연결 안 함)

  PC 터미널 설정: 115200 bps, 8-N-1, 흐름 제어 없음

4. 초기화 코드

4.1 DrvUart_Init()

void DrvUart_Init(void)
{
    static const IfxAsclin_Asc_Pins pins = {
        NULL,                        IfxPort_InputMode_pullUp,     /* CTS 미사용 */
        &IfxAsclin0_RXB_P15_3_IN,   IfxPort_InputMode_pullUp,     /* RX: P15.3 (X102 pin 32) */
        NULL,                        IfxPort_OutputMode_pushPull,  /* RTS 미사용 */
        &IfxAsclin0_TX_P15_2_OUT,   IfxPort_OutputMode_pushPull,  /* TX: P15.2 (X102 pin 31) */
        IfxPort_PadDriver_cmosAutomotiveSpeed1
    };

    IfxAsclin_Asc_Config cfg;
    IfxAsclin_Asc_initModuleConfig(&cfg, &MODULE_ASCLIN0);

    cfg.baudrate.baudrate    = 115200.0f;
    cfg.baudrate.prescaler   = 1u;

    cfg.frame.dataLength     = IfxAsclin_DataLength_8;
    cfg.frame.parityBit      = FALSE;               /* Parity 없음 */
    cfg.frame.stopBit        = IfxAsclin_StopBit_1;

    cfg.interrupt.txPriority    = DRVUART_TX_PRIORITY;   /* 3 */
    cfg.interrupt.rxPriority    = DRVUART_RX_PRIORITY;   /* 4 */
    cfg.interrupt.erPriority    = DRVUART_ERR_PRIORITY;  /* 2 */
    cfg.interrupt.typeOfService = IfxSrc_Tos_cpu0;

    cfg.pins         = &pins;
    cfg.txBuffer     = s_txBuffer;
    cfg.txBufferSize = UART_TX_BUFFER_SIZE;   /* 256 byte */
    cfg.rxBuffer     = s_rxBuffer;
    cfg.rxBufferSize = UART_RX_BUFFER_SIZE;   /* 64 byte */

    IfxAsclin_Asc_initModule(&s_asc, &cfg);
}

4.2 ISR

IFX_INTERRUPT(DrvUart_TxISR, 0, DRVUART_TX_PRIORITY)
{
    IfxAsclin_Asc_isrTransmit(&s_asc);
}

IFX_INTERRUPT(DrvUart_RxISR, 0, DRVUART_RX_PRIORITY)
{
    IfxAsclin_Asc_isrReceive(&s_asc);
}

IFX_INTERRUPT(DrvUart_ErrISR, 0, DRVUART_ERR_PRIORITY)
{
    IfxAsclin_Asc_isrError(&s_asc);
}

4.3 SW FIFO 버퍼 크기

/* iLLD FIFO: 실제 데이터 크기 + sizeof(Ifx_Fifo) + 8 바이트 필수 */
static uint8 s_txBuffer[UART_TX_BUFFER_SIZE + sizeof(Ifx_Fifo) + 8u];
static uint8 s_rxBuffer[UART_RX_BUFFER_SIZE + sizeof(Ifx_Fifo) + 8u];
iLLD FIFO 버퍼는 실제 데이터 크기 외에 sizeof(Ifx_Fifo) + 8 바이트를 추가로 확보해야 한다. 미준수 시 FIFO 내부 링 버퍼 처리에서 메모리 침범이 발생할 수 있다.

5. Echo 예제 동작

5.1 시작 메시지 (Cpu0_Main.c)

DrvUart_Init();
IfxCpu_enableInterrupts();

DrvUart_SendString("=== TC237 UART Echo Test ===\r\n");
DrvUart_SendString("Send any character -> TC237 echoes it back\r\n");
DrvUart_SendString("Ready.\r\n\r\n");

5.2 Echo 처리 (AppTask_1ms)

void AppTask_1ms(void)
{
    /* UART echo: PC에서 수신한 바이트를 그대로 반환
     * 예) PC에서 'a' 전송 → TC237이 'a' 회신 */
    uint8 rxByte;
    while (DrvUart_ReceiveByte(&rxByte))
    {
        DrvUart_SendByte(rxByte);
    }
}
while 루프 사용 이유: 1ms 태스크 주기 동안 RX FIFO에 여러 바이트가 쌓일 수 있다. if를 쓰면 한 번에 1바이트만 처리되어 고속 입력 시 FIFO 오버플로우 위험이 있다. while로 FIFO가 빌 때까지 모두 처리한다.

5.3 전체 Echo 신호 흐름

  PC 터미널에서 'a' 입력
        |
        v
  USB-TTL TX ──────────────────────────▶ P15.3 (ASCLIN0 RX)
                                               |
                                         DrvUart_RxISR()
                                         HW FIFO → SW RX FIFO 저장
                                               |
                                         AppTask_1ms() [1ms 주기]
                                         DrvUart_ReceiveByte() : 'a' 읽기
                                         DrvUart_SendByte('a')
                                               |
                                         DrvUart_TxISR()
                                         SW TX FIFO → HW FIFO → 송신
                                               |
  PC 터미널에 'a' 출력 ◀─────────────────── P15.2 (ASCLIN0 TX)
                                         USB-TTL RX

8. 핵심 설계 포인트

항목내용
핀 선정 이유 P14.0/P14.1은 보드 커넥터(X102, X103)에 미노출. P15.2(X102 pin 31) / P15.3(X102 pin 32)이 ASCLIN0 TX/RX로 사용 가능한 커넥터 노출 핀 중 가장 인접한 쌍
Non-blocking 수신 DrvUart_ReceiveByte()는 TIME_NULL 타임아웃으로 호출 — RX FIFO가 비어있으면 즉시 FALSE 반환. 협력형 스케줄러에서 태스크가 블로킹되지 않음
Blocking 송신 DrvUart_SendByte()는 blockingWrite 사용 — TX FIFO가 가득 차면 빌 때까지 대기. Echo 데이터 량이 적어 1ms 내 완료 가능하므로 허용
FIFO 이중 버퍼 ASCLIN 하드웨어 FIFO(4byte) + iLLD SW FIFO(TX 256 / RX 64 byte). ISR이 HW↔SW FIFO 간 데이터를 이송. 애플리케이션은 SW FIFO만 접근
시작 메시지 타이밍 IfxCpu_enableInterrupts() 이후에 SendString 호출. ISR이 활성화된 후 TX ISR이 정상 동작하므로 이 순서를 지켜야 함
