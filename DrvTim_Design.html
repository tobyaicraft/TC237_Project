GTM TIM PWM 캡처 추가 설계 문서

대상 MCU: Infineon AURIX TC237  |  iLLD: iLLD_1_20_0  |  작성일: 2026-05-02  |  작업: 기존 PWM 출력 프로젝트에 TIM 캡처 기능 추가

1. 프로젝트 개요

기존에 구축된 TC237 GTM TOM 기반 PWM 출력 프로젝트에 GTM TIM(Timer Input Module) PWM 캡처 드라이버(DrvTim)를 추가한다.
TOM0_Ch0이 출력하는 P00.9 핀의 PWM 신호를 TIM0_Ch0이 동일 핀에서 읽어 Duty Cycle과 Period를 측정한다.

신호 흐름:
TOM0_Ch0 → TOUT18 → P00.9 (push-pull 출력) → TIN18(INSEL 라우팅) → TIM0_Ch0 → ISR → 측정값 저장

2. 기존 드라이버 현황 (변경 없음)

파일 모듈 / 채널 핀 클럭 기능 ISR 우선순위
DrvPwm.c TOM0_Ch0 P00.9 (TOUT18) FXCLK2 = 390,625 Hz PWM 출력 (~100 Hz, Duty 가변) —
DrvGtmTimer.c TOM0_Ch1 없음 (출력핀 미사용) FXCLK1 = 6.25 MHz 1ms 스케줄러 tick ISR 11
⚠ 주의 (GTM 초기화 규칙): GTM enable / GCLK 설정은 DrvPwm_Init()에서만 수행한다. DrvGtmTimer, DrvTim 에서는 중복 호출하지 않는다.

4.2 핀 충돌 방지 방법

문제: TOM이 P00.9를 출력으로 설정했는데, TIM이 같은 P00.9를 입력으로 재설정하면 TOM 출력이 끊긴다.

해결: inputPinMode = IfxPort_InputMode_undefined 사용
→ IfxGtm_PinMap_setTimTin() 내부의 IfxPort_setPinModeInput() 호출이 건너뜀
→ GTM INOUTSEL.TIM[0].INSEL 라우팅 레지스터만 설정 (TIN18 선택자 = 1)
→ P00.9 포트 방향은 TOM의 출력 설정 그대로 유지 
cfg.filter.inputPin     = &IfxGtm_TIM0_0_TIN18_P00_9_IN;
cfg.filter.inputPinMode = IfxPort_InputMode_undefined;  /* 포트 방향 레지스터 변경 안 함 */
동작 원리:
TOM이 P00.9를 push-pull 출력으로 구동 → P00.9 핀 레벨이 결정됨
TC237 포트 아키텍처: 출력 모드에서도 입력 버퍼가 살아있어 구동 레벨을 읽을 수 있음
GTM INSEL 라우팅이 TIN18 경로를 통해 P00.9 레벨을 TIM으로 전달 → 외부 점퍼 불필요

4.3 PWM Measurement 동작 (Left-Aligned)

레지스터캡처 시점내용드라이버 멤버
GPR0 (CNTS)Active Edge (Rising)직전 High 구간 길이 [ticks]pulseLengthTick
GPR1 (CNT)Active Edge (Rising)직전 전체 주기 [ticks]periodTick
/* ISR: 100Hz PWM → 약 10ms 마다 호출 */
IFX_INTERRUPT(DrvTim_ISR, 0, DRVTIM_ISR_PRIORITY)
{
    IfxGtm_Tim_In_onIsr(&s_tim);   /* GPR0/GPR1 래치 → pulseLengthTick / periodTick 갱신 */
}

/* 측정값 조회 */
float32 duty   = IfxGtm_Tim_In_getDutyPercent(&s_tim, &coherent);
float32 period = IfxGtm_Tim_In_getPeriodSecond(&s_tim);

5. 소프트웨어 파일 구성

파일상태역할
Cpu0_Main.c수정#include "DrvTim.h" 추가, DrvTim_Init() 호출 추가
DrvTim.h신규ISR 우선순위 정의, DrvTim API 선언
DrvTim.c신규CLK0 활성화, TIM0_Ch0 초기화, ISR 정의
DrvPwm.h / .c변경없음TOM0_Ch0 PWM 출력 (P00.9)
DrvGtmTimer.h / .c변경없음TOM0_Ch1 1ms 타이머 ISR
DrvIntc / DrvDio / DrvAdc / Scheduler변경없음기존 기능 유지

초기화 순서 (Cpu0_Main.c)

void core0_main(void)
{
    DrvIntc_Init();       /* WDT 비활성화 */
    DrvDio_Init();
    DrvAdc_Init();
    DrvPwm_Init();        /* GTM enable, GCLK=100MHz, FXCLK enable, TOM0_Ch0 PWM 시작 */
    DrvGtmTimer_Init();   /* TOM0_Ch1 1ms 타이머 (FXCLK 이미 활성화됨) */
    DrvTim_Init();        /* CLK0 추가 활성화, TIM0_Ch0 캡처 초기화       ← 신규 */

    IfxCpu_enableInterrupts();

    while (1) { Scheduler_Run(); }
}
