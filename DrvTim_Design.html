GTM TIM0 Ch0 PWM 입력 캡처 드라이버 설계

TC237 Aurix Project  |  DrvTim.c / DrvTim.h  |  작성일: 2026-05-02

1. 개요

GTM TIM0 Ch0 을 사용하여 TOM0 Ch0 이 출력하는 100Hz PWM 신호의 Duty Cycle과 Period를 측정한다. TOM 출력 핀(P00.9)에서 점퍼 와이어로 TIM 입력 핀(P00.0)에 신호를 연결하여 포트 충돌 없이 독립적으로 측정한다.

항목내용
측정 모드PWM Measurement (Left-Aligned) — Rising edge 기준 주기 측정
측정 대상DrvPwm (TOM0_Ch0) 출력, 100Hz / 초기 Duty 50%
TIM 모듈GTM TIM0, Channel 0
입력 핀P00.0 (TIN9) — P00.9에서 점퍼 와이어 연결
캡처 클럭CMU_CLK0 = 100 MHz
ISR 우선순위5 (DrvGtmTimer ISR 11과 충돌 없음)

2. 하드웨어 연결

구분핀방향기능비고
TOM 출력P00.9출력TOUT18 — 100Hz PWM 신호 출력DrvPwm, push-pull 구동
TIM 입력P00.0입력TIN9 — PWM 신호 캡처No Pull Device, 점퍼 연결
하드웨어 연결: P00.9 (TOM 출력) ─── 점퍼 와이어 ───> P00.0 (TIM 입력)

P00.9는 TOM이 push-pull로 구동하는 출력 전용 핀이다. P00.0을 별도 입력 핀으로 지정함으로써 포트 방향 레지스터 충돌을 완전히 회피한다. inputPinMode = IfxPort_InputMode_noPullDevice를 사용하며, 핀이 TOM에 의해 능동 구동되므로 pull 저항은 불필요하다.

3. 클럭 체인

단계클럭주파수설정 위치
GTM 모듈 클럭fSOURCE / GTMDIV100 MHzDrvPwm_Init()
GTM GCLKGCLK = fMod100 MHzDrvPwm_Init()
FXCLK2 (TOM용)FXCLK2 = GCLK / 256390,625 HzDrvPwm_Init()
CMU_CLK0 (TIM용)CLK0 = GCLK / 1100 MHzDrvTim_Init()
CLK_EN 레지스터 2-bit 필드 의미: 0b00 = 변경없음  |  0b01 = disable  |  0b10 = enable
IFXGTM_CMU_CLKEN_CLK0 = 0x00000002는 EN_CLK0 필드만 enable(0b10), 나머지(FXCLK 포함)는 0b00(변경없음). 기존 TOM 클럭에 영향 없음.

4.3 초기화 코드

void DrvTim_Init(void)
{
    Ifx_GTM *gtm = &MODULE_GTM;

    /* CMU_CLK0 = 100 MHz 활성화 */
    float32 fMod = IfxGtm_Cmu_getModuleFrequency(gtm);
    IfxGtm_Cmu_setClkFrequency(gtm, IfxGtm_Cmu_Clk_0, fMod);
    IfxGtm_Cmu_enableClocks(gtm, IFXGTM_CMU_CLKEN_CLK0);

    IfxGtm_Tim_In_Config cfg;
    IfxGtm_Tim_In_initConfig(&cfg, gtm);

    cfg.timIndex            = IfxGtm_Tim_0;
    cfg.channelIndex        = IfxGtm_Tim_Ch_0;
    cfg.irqMode             = IfxGtm_IrqMode_pulseNotify;
    cfg.isrProvider         = IfxSrc_Tos_cpu0;
    cfg.isrPriority         = DRVTIM_ISR_PRIORITY;      /* 5 */

    cfg.capture.clock       = IfxGtm_Cmu_Clk_0;         /* 100 MHz */
    cfg.capture.irqOnNewVal = TRUE;
    cfg.capture.mode        = Ifx_Pwm_Mode_leftAligned;

    cfg.filter.inputPin     = &IfxGtm_TIM0_0_TIN9_P00_0_IN;   /* P00.0 */
    cfg.filter.inputPinMode = IfxPort_InputMode_noPullDevice;

    cfg.mode                = IfxGtm_Tim_Mode_pwmMeasurement;

    IfxGtm_Tim_In_init(&s_tim, &cfg);
}

4.4 ISR

IFX_INTERRUPT(DrvTim_ISR, 0, DRVTIM_ISR_PRIORITY)
{
    IfxGtm_Tim_In_onIsr(&s_tim);
}
IFX_INTERRUPT 매크로의 세 번째 인수(우선순위)는 괄호 없이 정수 리터럴 또는 매크로로 지정해야 한다. 괄호 사용 시 어셈블러 섹션 이름 생성 오류 발생.

{

7. 핵심 설계 포인트

항목내용
핀 분리 TOM 출력(P00.9)과 TIM 입력(P00.0)을 다른 핀으로 분리. 포트 방향 레지스터 충돌 원천 차단, inputPinMode_undefined 트릭 불필요
CLK0 독립 활성화 IFXGTM_CMU_CLKEN_CLK0 = 0x00000002 — EN_CLK0 필드만 enable, FXCLK 필드는 변경없음(0b00). 기존 TOM 동작에 영향 없음
초기화 순서 DrvPwm_Init()이 GTM enable + GCLK + FXCLK를 담당. DrvTim_Init()은 CMU_CLK0만 추가. 순서 바뀌면 GTM 비활성 상태에서 CMU 설정 시도하여 오동작 가능
coherent 읽기 iLLD getDutyPercent() 내부의 coherent 플래그로 ISR 갱신 중 mid-update 읽기 방지. 현재 플래그 값은 무시하고 반환값만 사용
ISR 빈도 일치 100Hz PWM → TIM ISR 10ms마다 발생. AppTask_10ms 호출 주기와 동일하므로 매 태스크 사이클에서 최신 측정값 획득
