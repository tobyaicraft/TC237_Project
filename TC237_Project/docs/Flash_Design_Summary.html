DFLASH 캘리브레이션 드라이버 설계 요약

MCU: Infineon AURIX TC237L  |  모듈: DrvFlash  |  파일: DrvFlash.c / DrvFlash.h

1. 개요

DFLASH(Data Flash)를 이용하여 캘리브레이션 데이터(PWM Duty 등)를 비휘발성으로 저장하고, 전원 재투입 시 자동으로 복원하는 드라이버이다. UART 명령을 통해 런타임에 값을 변경하고 Flash에 저장/로드할 수 있다.

2. 메모리 맵

3. 데이터 구조체

typedef struct
{
    uint8  pwmDuty;      /* PWM Duty 0~100 [%]           (1 byte)  */
    uint8  reserved1;    /* 예약 (확장용)                (1 byte)  */
    uint16 reserved2;    /* 예약 (확장용)                (2 bytes) */
    uint32 magic;        /* 유효성 검증 매직넘버          (4 bytes) */
} DrvFlash_CalData;      /* 총 8 bytes = 1 DFLASH page             */

#define DRVFLASH_CAL_MAGIC  0xCAFE1234u

메모리 배치 (리틀엔디안)

OffsetByte 0Byte 1Byte 2Byte 3Byte 4Byte 5Byte 6Byte 7
0xAF000000 pwmDutyreserved1reserved2 0x340x120xFE0xCA
예: Duty=75 0x4B0x000x000x00 0x340x120xFE0xCA
예: Duty=80 0x500x000x000x00 0x340x120xFE0xCA
매직넘버의 목적: Flash 영역에 유효한 데이터가 기록되어 있는지 판별한다. Erase 직후 Flash는 전부 0x00이므로, magic이 0xCAFE1234가 아니면 "저장된 적 없음"으로 판단하여 기본값을 사용한다.

5. Flash Read 시퀀스 (DrvFlash_LoadCalibration)

DFLASH는 메모리 맵 I/O이므로 별도의 Flash 명령 없이 포인터로 직접 읽는다.

const DrvFlash_CalData *pFlash = (const DrvFlash_CalData *)0xAF000000;

if (pFlash->magic == 0xCAFE1234)    → 유효 → g_pwmDuty 복원
if (pFlash->magic != 0xCAFE1234)    → 무효 → 기본값 유지 (FALSE 리턴)

6. UART 명령 인터페이스

통신 설정: 115200 bps, 8-N-1  |  줄 끝: CR / LF / CR+LF 모두 가능  |  대소문자: 대문자만 인식

명령동작응답 (성공)응답 (실패)
D=xxPWM Duty 즉시 변경 (RAM만)[CAL] Duty=xx-
SAVERAM → Flash 저장[CAL] Saved! Duty=xx[CAL] Save FAILED!
LOADFlash → RAM 복원[CAL] Loaded! Duty=xx[CAL] No valid data in Flash
CAL?현재 Duty 값 조회[CAL] Duty=xx-

7. 사용 시나리오

순서조작결과
1전원 ON부팅 시 DrvFlash_LoadCalibration() 자동 호출 (첫 실행 시 기본값)
2터미널에서 D=75 입력PWM Duty 75%로 즉시 변경 (RAM만)
3터미널에서 CAL? 입력현재 값 확인 → [CAL] Duty=75
4터미널에서 SAVE 입력Flash에 저장 → [CAL] Saved! Duty=75
5전원 OFF → ON자동으로 75% 복원
주의: D=75만으로는 Flash에 저장되지 않는다. 반드시 SAVE 명령을 실행해야 전원을 꺼도 값이 유지된다.
