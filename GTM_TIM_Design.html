GTM TOM/TIM PWM 출력 및 캡처 설계 문서

대상 MCU: Infineon AURIX TC237  |  iLLD 버전: iLLD_1_20_0  |  작성일: 2026-05-02

1. 개요

본 설계는 TC237의 GTM(Generic Timer Module) 내 TOM(Timer Output Module)을 이용하여 1kHz / 25% Duty PWM 신호를 생성하고, 동일 GTM의 TIM(Timer Input Module)으로 해당 신호의 주기(Period)와 Duty Cycle을 측정하는 구조이다.

핵심 동작 흐름:
TOM0_CH4 → P02.8 (PWM 출력) → [외부 점퍼] → P02.3 → TIM0_CH3 (PWM 캡처) → ISR → 측정 결과 저장

3.2 PWM 파라미터 계산

파라미터계산식결과
목표 주파수—1,000 Hz (1 kHz)
목표 Duty—25 %
Period Ticks12,500,000 / 1,00012,500 ticks
Duty Ticks12,500 × 0.253,125 ticks
16-bit 범위 확인12,500 ≤ 65,535✓ 정상
TOM PWM 동작 원리:
CN0 카운터가 0에서 시작 → CM0(= Duty Ticks)에 도달 시 출력 반전 → CM1(= Period Ticks)에 도달 시 다시 반전 후 리셋.
결과: HIGH 구간 = 3,125 ticks (0.25ms), LOW 구간 = 9,375 ticks (0.75ms), 총 주기 = 1ms

4.2 TIM PWM Measurement 동작 원리

레지스터캡처 시점저장 내용
GPR0 (= CNTS)Active Edge (Rising) 발생 시직전 펄스 길이 (High 시간) [ticks]
GPR1 (= CNT)Active Edge (Rising) 발생 시직전 전체 주기 [ticks]
Left-Aligned PWM 측정 동작:
① Rising Edge 감지 → GPR1에 현재 CNT(주기 카운터) 래치, CNT 리셋
② Falling Edge 감지 → CNTS(펄스 길이 카운터) 정지, GPR0에 래치
③ 다음 Rising Edge → NEWVAL 인터럽트 발생 → ISR에서 GPR0/GPR1 읽기

예상 측정값 (1kHz / 25% / CLK0=200MHz):
 • GPR1 (periodTick) ≈ 200,000 ticks → Period = 200,000 / 200,000,000 = 1.0 ms
 • GPR0 (pulseLengthTick) ≈ 50,000 ticks → Duty = 50,000 / 200,000 × 100 = 25.0 %

5. 하드웨어 연결

TOM 출력(P02.8)을 TIM 입력(P02.3)과 물리적으로 연결해야 측정이 가능합니다.
